Fireworkz for Linux - Help

This is Fireworkz for Linux (KDE Plasma and other desktops using Qt 6), a port of the Windows version. The manuals are on the web, listed below: they were written for RISC OS and Windows, and the menus, dialogue boxes, keys and files work in the same way, with the desktop's own file, print and colour choosers.

Keys: F1 opens this help; Ctrl+O opens a document, Ctrl+S saves it and Ctrl+P prints it; the other shortcuts are shown beside the menu items.

Online Resources

Many resources for Fireworkz are freely available online:

  • Getting Started Guide;
  • User Guide;
  • Addenda and Errata - updates since the documentation was printed, and errata therein;

Support

web site: https://groups.google.com/group/colton-software-fireworkz
e-mail: colton-software-fireworkz@googlegroups.com
